We will design a URL Shortener where users can convert long URLs into short, unique URLs using a UrlShortenerService. We'll create a ShortCodeGenerator interface with different implementations, such as RandomCodeGenerator, which generates a random 7-character alphanumeric string, and CounterCodeGenerator, which generates an incremental ID and converts it into Base62. For the initial implementation, we'll use random code generation and a ConcurrentHashMap to store the mapping between the short code and the original URL. To avoid collisions when multiple requests arrive concurrently, we'll use putIfAbsent() and generate another code if the code already exists. We'll create a UrlMapping class containing the short code, original URL, optional expiry timestamp, and click count. Users can also provide custom aliases, provided the alias is not already taken. When someone accesses a short URL, the UrlRedirectService will retrieve the mapping, check whether the URL has expired, increment the click count, and return the original URL for redirection. We can also introduce a scheduled cleanup task to remove expired URLs periodically, while handling invalid codes, duplicate aliases, and expired links with appropriate errors.
