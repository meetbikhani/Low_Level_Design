The Movie Booking System consists of classes such as City, Movie, Theatre, Screen, Show, Seat, User, and Booking, with services responsible for managing movies, shows, theatres, and bookings. A user can select a city, movie, theatre, showtime, and seats before proceeding with the booking. When the user selects seats, the system locks those seats temporarily by changing their status from AVAILABLE to LOCKED, ensuring that concurrent users cannot book the same seats simultaneously. A scheduler is used to automatically release seats whose temporary lock expires after a fixed time if the booking has not been completed, changing their status back to AVAILABLE; if the user successfully completes the booking and payment within the allotted time, the seats are marked as BOOKED and the lock is released. The booking flow can use synchronization on show to prevent race conditions during seat locking, while a Strategy Pattern can support different payment methods, and an Observer Pattern can notify users about booking confirmation, payment status, or cancellation. The scheduler handles expired seat locks automatically, preventing seats from remaining unavailable when users abandon the booking process. 



public class SeatLockManager {
    private final Map<Show, Map<Seat, String>> lockedSeats = new ConcurrentHashMap<>();
    private final ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);
    private static final long LOCK_TIMEOUT_MS = 500; // 0.5 seconds. In real world, timeout would be in minutes

    public void lockSeats(Show show, List<Seat> seats, String userId) {
        synchronized (show) { // Synchronize on the show to ensure atomicity for that specific show
            // Check if any of the requested seats are already locked or booked
            for (Seat seat : seats) {
                if (seat.getStatus() != SeatStatus.AVAILABLE) {
                    System.out.println("Seat " + seat.getId() + " is not available.");
                    return;
                }
            }

            // Lock the seats
            for (Seat seat : seats) {
                seat.setStatus(SeatStatus.LOCKED);
            }

            lockedSeats.computeIfAbsent(show, k -> new ConcurrentHashMap<>());
            for (Seat seat : seats) {
                lockedSeats.get(show).put(seat, userId);
            }

            // Schedule a task to unlock the seats after a timeout
            scheduler.schedule(() -> unlockSeats(show, seats, userId), LOCK_TIMEOUT_MS, TimeUnit.MILLISECONDS);
            System.out.println("Locked seats: " + seats.stream().map(Seat::getId).toList() + " for user " + userId);
        }
    }
