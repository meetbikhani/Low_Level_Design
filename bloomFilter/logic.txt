A Bloom Filter is a probabilistic data structure used to efficiently check whether an element might exist in a dataset. I would design it with a BloomFilter class that maintains a fixed-size bit array and a collection of hash functions. Whenever an element is inserted, the Bloom Filter passes it through all the configured hash functions, calculates the corresponding indexes, and sets those bits to 1 in the same bit array. To check whether an element exists, it calculates the same indexes and checks whether all corresponding bits are set. If any bit is 0, the element definitely doesn't exist; if all bits are 1, the element might exist, as collisions can cause false positives. I would use the Strategy Pattern through a HashFunction interface with implementations such as Java Hash and FNV-1a, allowing hash algorithms to be changed independently. A BloomFilterBuilder would configure the bit-array size and hash functions. The number of hash functions and bit-array size can be determined based on the expected number of elements and acceptable false-positive probability.
