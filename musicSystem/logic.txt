The Music Streaming System consists of entities such as Artist, Song, Album, User, and Playlist. The system allows administrators to add artists, create songs, organize songs into albums, and associate albums with artists. Users can register with either a FREE or PREMIUM subscription type using an enum, browse and search for songs by title, artist, album, or genre, follow artists if their subscription permits it, and create playlists containing their favourite songs. A MusicPlayer manages playback operations such as play, pause, next, and previous, while the Strategy Pattern is used to implement different playback policies for free and premium users. Free users can listen to a limited number of songs before an advertisement is played, while premium users can enjoy uninterrupted playback. The number of songs played should be tracked separately for each user's playback session to prevent ad counters from being shared between users. A recommendation service can use the Strategy Pattern with different recommendation strategies, such as genre-based or artist-based recommendations, to suggest relevant songs. The system can also include an Observer Pattern to notify users about new releases from followed artists, playlist updates, or other relevant events, while dedicated services manage user registration, artist following, playlists, search, recommendations, and playback.
